# Compilador Sindarin → Arduino Mega 2560

Trabalho prático de Compiladores, IFF, prof. Fabrício.
Dupla: **Amanda** (`amandamoraes19`) e **Artur** (`potentus-pixel`).

O compilador lê programas escritos em Sindarin e gera código Arduino C++ para o Arduino Mega 2560.
Ele usa Java, Maven e ANTLR 4.

## Etapas

| Etapa | Situação |
| :--- | :--- |
| 1. Especificação léxica e analisador léxico | 🔨 em andamento |
| 2. Especificação sintática e analisador sintático | ⏳ |
| 3. Árvore sintática abstrata | ⏳ |
| 4. Análise semântica e tabela de símbolos | ⏳ |
| 5. Representação para geração de código | ⏳ |
| 6. Geração de código Arduino C++ | ⏳ |
| 7. Integração e validação para Arduino Mega | ⏳ |

## Como trabalhamos

Cada etapa tem uma Issue e é feita numa branch própria. A branch entra na `main` por Pull Request, depois da revisão do outro integrante.
